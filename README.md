## 项目一：基于 ELK 的 Web / SSH 日志安全分析与告警平台

|  |  |  |  |
| --- | --- | --- | --- |
| **技术栈**：Elasticsearch | Kibana | Logstash | Docker Compose | Grok |

Docker Compose 单机部署 ELK 8.11，打通「日志采集 → 解析入库 → 可视化 → 告警 → 告警分析 → 报告输出」全链路。

- **多源日志分流**：用 `tags` 区分 Web 访问日志与 Linux 认证日志，避免 glob 重叠导致的数据静默翻倍
- **两层 Grok 解析**：信封层（时间戳 / 主机名 / 进程 / PID）+ 正文层（用户名 / 来源 IP），归一化为 6 类客观事件类型，并保留 `else` 兜底用于发现日志格式变化
- **真实数据接入**：公开数据集 17,335 行 + 自建认证日志 446 行，实现 **100% 解析、零失败**
- **可视化与告警**：2 个仪表盘（共 9 面板）+ 2 条告警规则（404 突增 / 畸形 UA）
- **告警分析报告**：从 280 次 404 中定位 2 个攻击源（字典化目录枚举 + 单点认证爆破），判定均未成功并给出三层处置建议
- **沉淀 6 条「静默失败」踩坑记录**：Grok 括号错位 / 时区静默失效 / 多配置被合并加载 / inode 复用致重读失败 / 数据卷路径笔误 / 阈值规则盲区
